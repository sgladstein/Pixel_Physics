# Old project memory (copied 2026-10-27)

A verbatim copy of the 103 files of project memory from the old account, taken at the move. `MEMORY.md` is the index
every session loaded at start; each other file is one subject, with frontmatter and `[[links]]` to related files.

**This is a dated record, not live state.** Each file says when it was written. File paths, switches and numbers
in it were true then; check them against the code before relying on one. Thread ids (`cmsg_...`), session ids and
`claude.ai/artifact/...` links belong to the old account and will not open from the new one.

The memory holds three kinds of thing:
- **Owner rulings** (`type: feedback` and the rule lines in `MEMORY.md`): the working practices summarised in the
  master README §5. These are the part most worth carrying into the new project's memory or instructions.
- **Lane state and batch histories** (`type: project`): which thread did what, with numbers. Most of it has since
  landed in `Reports/`; the Teacher lane's batch log is the record of the ant line.
- **References**: thread ids, tools, recipes.

No secrets were found in it when it was copied (it records environment variable names only).
