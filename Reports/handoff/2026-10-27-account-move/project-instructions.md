# Project instructions (old project, as configured at 2026-10-27)

These were the standing instructions every thread in the old Claude project received. Copied verbatim:

> Before a thread finishes or is resolved, land its work so future sessions can find it:
> - Reports, findings and decisions go into the repo (Reports/, and Reports/how-we-test.md for testing rules) via a PR to the Merge desk.
> - Lasting rules and guidelines also go into project memory.
> - Message any active thread whose work the findings affect (the Teacher lane for anything about ant training).
> A thread is not done until all three are checked.
>
> Defaults: new features ship ON by default, in training and the lab. Leave a feature off only when there is real uncertainty about whether it helps (and say why). If turning a feature on changes ant-training results, tell the Teacher lane before it lands.
